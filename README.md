# რუსული ანბანი — სათამაშო ენციკლოპედია (PWA)

5 კლასის მოსწავლეებისთვის შექმნილი თვალსაჩინო საგანმანათლებლო ვებაპლიკაცია (PWA) რუსული ანბანის (33 ასო) და 90 სიტყვის შესასწავლად, რეალისტური ილუსტრაციებით, ხმოვანი გახმოვანებით და თითით წერის დაფით.

## ფუნქციები
- **ანბანის გზამკვლევი (33 ასო)**: ქართული ტრანსკრიფცია, „ცრუ მეგობრების“ გაფრთხილება, გამოთქმა და ასოს შემოხაზვა.
- **სასწავლო თამაშები**: ასოების ქვიზი, სიტყვების აწყობა 3 სირთულის დონეზე (90 სიტყვა), სურათებიანი ლექსიკონი ძიებით, „იპოვე სურათი“, მეხსიერების ბარათები და დღის გამოწვევა.
- **PWA მხარდაჭერა**: Web App Manifest (`manifest.webmanifest`), Service Worker უსაფრთხო ქეშირებით, აპლიკაციის დაყენება Android / Desktop / iPhone-ზე და განახლების შეტყობინება.
- **კონფიდენციალურობა**: პროგრესი ინახება მხოლოდ მომხმარებლის მოწყობილობაზე (`localStorage`); კლიენტის მხარეს API გასაღებები არ გამოიყენება.

## ლოკალური გაშვება
```bash
npm install
npm run dev
```

## Production აწყობა და გაშვება
```bash
npm run build
npm start
```
